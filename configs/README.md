# configs/

Two kinds of YAML: **train configs** (`stage*.yaml`, read by `scripts/train.py`) and **data recipes** (`data_*.yaml`,
read by `scripts/prepare_data.py`). Train configs inherit with `base: <file>` (path relative to this folder), so the
folder is kept flat. Override any key on the command line: `--set train.max_steps=100`.

## The v0.1 lineage (what actually produced the weights)

| Stage | Train config (inheritance chain) | Data recipe |
|---|---|---|
| S0 smoke | `stage0_kaggle.yaml` ← `base.yaml` | `data_stage0_kaggle.yaml` |
| **S1** | `stage1_pilot.yaml` ← `base.yaml` | `data_stage1.yaml` |
| **S2** | `stage2_full_C.yaml` ← `stage2_pilot_C.yaml` ← `stage2_pilot_B.yaml` ← `stage2_pilot_A.yaml` ← `base.yaml` | `data_stage2_full.yaml` (generated by `scripts/make_stage2_full_recipe.py` from `data_stage2_abl_E2.yaml` + `data_stage2.yaml`) |
| **S3 = v0.1** | `stage3_longctx.yaml` ← `stage2_pilot_C.yaml` ← … | `data_stage3.yaml` |

## Experiments (kept for the record, not in the lineage)

- `stage2_pilot_{A,B,C}.yaml` + `data_stage2_pilot.yaml`: 1,500-step arm comparison (chose C).
- `stage2_abl_*.yaml` + `data_stage2_abl_*.yaml`: data ablations (E2 mix chosen; E3/C0 defined but not run).
- `speedtest_*.yaml`, `stage2_fast_*.yaml`: throughput tests (batch 4 × 8, no checkpointing chosen).
- `stage2_scale.yaml`, `data_stage2.yaml`: the original Stage 2 plan; `data_stage2.yaml` supplies source sizes to the full recipe.
- `stage1_control_modernbert.yaml`: same-recipe ModernBERT control — **defined but never run**.
- `*_smoke*.yaml`, `stage0_smoke.yaml`, `data_stage0.yaml`: CPU smoke tests (`scripts/smoke_cpu.sh`, `tests/`).

Note: the `HWU64` comment in the S2 recipes says eval overlap "none", but MASSIVE (an eval set) shares 56 of HWU64's
59 intent names (different texts). MASSIVE is therefore not a fully zero-shot set for v0.1; the 12-set
"zero-shot" average in the model card already excludes it.
