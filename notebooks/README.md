# notebooks/

The Kaggle notebooks that ran each job (outputs stripped, no credentials). They were generated by
`scripts/kaggle/build_*notebook*.py` and run on Kaggle **2× T4** with the code uploaded as a private Kaggle dataset
(`ultragliclass-code`) in the **original flat layout** (`train.py`, `prepare_data.py`, `ugc/` at the bundle root).
To re-run one from this repo, build a flat bundle (`scripts/kaggle/make_code_bundle.py`, paths may need adjusting) or
change the notebook's `python train.py` calls to `python scripts/train.py` after `pip install -e .`.

| Notebook | Job | Kaggle kernel |
|---|---|---|
| `kaggle_stage1.ipynb` | S0 smoke + S1 | `ultragliclass-s0a`, `-s0b`, `-s1` |
| `kaggle_stage2_pilot.ipynb` | S2 pilots A/B/C | `ultragliclass-s2pilot` |
| `kaggle_speedtest_fast.ipynb` | throughput test | `ultragliclass-speedtest` |
| `kaggle_stage2_ablation.ipynb` | S2 data ablations | `ultragliclass-s2ablation` |
| `kaggle_stage2_full.ipynb` | S2 full (2 sessions) | `ultragliclass-s2full` |
| `kaggle_stage3.ipynb` | S3 smoke + full (`MODE=smoke/full`) | `ultragliclass-s3smoke`, `-s3full` |
| `kaggle_eval_readme.ipynb` | README benchmark | `ultragliclass-evalreadme` |
